# X 光安检判图训练系统

纯浏览器运行的 X 光安检判图训练台：物品三维建模后在 GPU 上实时合成双能 X 光图像，TypeScript + WebGL2 手写着色器，题库与成绩存 IndexedDB，零后端、零运行时 UI 依赖。

## 快速开始

```bash
npm install
npm run dev          # 开发服务器
npm run build        # 类型检查 + 生产构建
npm run verify:physics   # 物理模型验证（Beer-Lambert / 双能分类 / 叠压可加）
npm run test:smoke       # 端到端冒烟测试（真实体素化代码路径）
```

## 物理模型（核心）

### 1. 体素化与 Beer-Lambert 衰减

- 每件物品由简单几何体（长方体/球/圆柱/圆锥/椭球）拼搭，每个部位标注材质与密度
- CPU 侧将场景光栅化进 3D 体素网格，每体素累加低能/高能线性衰减系数 μ
- 同体素内多材质叠压时 μ 直接相加（光程相同），天然支持物品叠压
- GPU 光线步进沿射线累加光程 `A = Σμ·dz`，透射强度 `I = I₀·exp(-A)`
- 厚度翻倍时 `I(2t)/I(t) = exp(-μ·t)`，严格指数衰减

### 2. 双能材质判别

- 低能有效能量 55keV、高能 110keV（双能安检机典型有效能量）
- 材质 μ 值参照 NIST XCOM 数据库标定，覆盖 23 种常见材质
- 判别指标 `R = A低/A高`（与厚度无关）：
  - `R ≤ 1.68` 有机物（橙）：水、塑料、织物、食品、锂电芯等
  - `1.68 < R < 2.25` 混合物（绿）：玻璃、陶瓷、混凝土
  - `R ≥ 2.25` 无机物（蓝）：钢、铜、铝、铅等金属
- 阈值落在相邻材质 R 值间隙中央，预留壳体叠压的离散化裕度

### 3. 验证结果

| 验证项 | 结果 |
| --- | --- |
| 指数衰减（23 材质厚度翻倍） | 全部通过，误差 < 1e-12 |
| 解析公式双能分类（207 采样） | 100%（目标 ≥95%） |
| 端到端体素化分类（23 材质真实管线） | 100% |
| 叠压光程可加、顺序无关 | 通过 |
| 随机组包投影完整性（5 种子） | 全部物品有投影、bbox 归一化、遮挡率有界 |

## 架构

```
src/
  core/            领域逻辑（无 DOM 依赖，可独立 Node 测试）
    materials.ts   材质物理参数与双能阈值
    math3d.ts      向量/矩阵（列主序 Mat4，含仿射求逆）
    geometry.ts    物品基元 -> 世界空间基元、包含测试、世界 AABB
    voxelizer.ts   场景体素化、双能 μ 累加、投影与遮挡率
    packing.ts     规则随机装包、难度三因子（遮挡/朝向/拥挤）
    grading.ts     IoU 贪心匹配、漏判/误判/类别错误统计
    items/         80 种物品定义（24 违禁品 + 56 普通品）
    profiles.ts    三类机型伪彩配置
    question_service.ts  组包->体素化->GroundTruth 流水线
    training_session.ts 限时训练会话状态机
    exchange.ts    题库导入导出
  render/          WebGL2 渲染
    gl_utils.ts    着色器编译、FBO、3D 纹理
    shaders.ts     光线步进 + 双能分类伪彩 + 增强 GLSL
    xray_renderer.ts 两遍渲染管线
  data/idb.ts      IndexedDB 封装（题目/试卷/成绩/学员/设置）
  ui/              查看器、路由 store、Toast、线性图标
  pages/           物品库/组包/训练/考核/分析/设置 六个页面
scripts/
  verify_physics.ts  物理公式验证
  smoke_test.ts      端到端冒烟（esbuild 打包后 Node 运行）
```

## 功能与页面对照

| 页面 | 能力 |
| --- | --- |
| 物品库 | 80 种物品检索、几何体构成与材质 μ/R 值详情 |
| 行李组包 | 手动摆放（位置/姿态滑块）、规则随机装包、实时 X 光预览、存为题目 |
| 判图训练 | 限时出图、拖框标注、四类增强（超级增强/反色/边缘/局部放大）、即时复盘 |
| 考核 | 按遮挡/朝向/杂物难度自动组卷，题库不足时随机装包即时生成 |
| 成绩分析 | 按违禁品类别统计命中率，弱项排序，历史考核记录 |
| 设置 | 机型伪彩切换、体素精度、IoU 阈值、学员管理、题库导入导出 |

## 图像增强（对齐真机操作）

- 伪彩/灰度/反色三种模式
- 超级增强：弱光程区域对数压缩 + 伽马提亮
- 边缘增强：Sobel 算子提取轮廓
- 局部放大：以指针为中心 1~4 倍滚轮缩放

## 数据与共享

所有数据存浏览器 IndexedDB，无需联网。题库可导出为 JSON bundle（含题目、试卷、物品定义），其他培训点通过设置页导入即可共用。

## 已知边界

- 体素分辨率默认 128³，可在设置切换 80~160；分辨率越高细节越精细但体素化越慢
- 薄板壳体在低分辨率下因离散化会被轻微放大，验证脚本以实测壳体光程为基准扣除
- 几何包含测试为 CPU 计算，已按基元世界 AABB 裁剪遍历范围；单题体素化在默认精度下为毫秒级
